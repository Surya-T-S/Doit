# Security Policy

## Supported Versions

We release patches and security updates for the current major and minor versions.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within **Doit**, please do **NOT** open a public issue.

Instead, please report security advisories privately via [GitHub Security Advisories](https://github.com/Surya-T-S/Doit/security/advisories/new) or contact the project maintainer via private GitHub channels.

You will receive an acknowledgment within 48 hours. Valid vulnerabilities will be addressed promptly with an update release.
